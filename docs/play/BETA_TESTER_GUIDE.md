# Angle Lens closed test: tester guide (1.0.0-rc1)

Thanks for testing. Angle Lens reads angles from your camera. It is **not calibrated yet**, so please
check every reading you depend on with a real protractor, and tell us how far off it was.

## Install
1. Accept the closed-test invite link and install **Angle Lens** from Google Play.
2. If you had a test copy installed from a file before, uninstall it first.

## Try these
1. **Start Camera.** Allow camera access. (Also try Deny once: the app should explain and offer Open Photo.)
2. **AR Lock.** Aim the bend at the crosshair, tap **AR Lock**, drag the two arm handles onto the two edges.
3. **Freeze & Measure.** Tap the corner, then a point on each edge. Drag points to adjust.
4. Tap the **interior** button to cycle interior / supplement / exterior.
5. **Lock** the reading, then **Save** and pick where the image goes.
6. **Open Photo** and measure a picture from your gallery.
7. Turn the phone sideways and back; switch to another app and back.
8. Turn on airplane mode and repeat step 2 (it should still work).

## Report each issue with
- Phone model and Android version
- What you did, what you expected, what happened (screenshot or screen recording if possible)
- For readings: the reference angle, the app's reading, the material and lighting, and whether the phone was square to the bend

- [ ] Camera started and the permission prompt made sense
- [ ] AR Lock handles were easy to drag onto edges
- [ ] Reading stayed steady when I lifted my finger
- [ ] Buttons were all visible without hunting (note screen size if not)
